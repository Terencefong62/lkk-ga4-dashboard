    Remarks

    1. Bot-like traffic is a dashboard definition, not Google Analytics’ built-in bot detection. A session is treated as bot-like if (1) it belongs to a source/medium whose average session duration is 0:00 in the selected period, or (2) it is a China session whose average duration is 0–3 seconds (China on desktop when that split is available). If a day’s remaining time on site is still 0–3 seconds after rule 1, every China session that day is also treated as bot-like.
    2. Bot-like traffic is removed from sessions, users, page views, Page views / session, and time on site in the KPI cards, trend chart, domain ranking, donuts, and Actionable Insights. Product and recipe lists are not split by country and are not reduced by the China 0–3s rule. Zero-time source/medium groups are still excluded from the Source / medium donut.
    3. Page views / session is page views ÷ sessions after those filters.
    4. A domain must be selected before any data is shown.
    5. The date range is limited to the current snapshot (). A previous-period or year-ago comparison can fall outside that window; those days appear empty.
    6. Average time on site is averaged only across days that still have a duration after the exclusions above.
    7. Domain ranking and What visitors are viewing show the five domains with the most remaining sessions.
